# KPI-Pulse
DEMO! Легковесное десктоп-приложение для мониторинга ключевых показателей эффективности (KPI) в реальном времени. Построено на Avalonia UI и .NET 8, работает на Windows, Linux и macOS из одного кода. Демонстрирует современный подход к разработке кроссплатформенных приложений с использованием MVVM, реактивного программирования и кастомных контролов.
